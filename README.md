# Portfólio de Juliano Pereira Cândido

Portfólio de desenvolvedor .NET com informações de contato, acesso aos repositórios e as tecnologias que utilizo em sistemas desktop, aplicações web e APIs.

[Visitar o portfólio](https://somasolucoesdigitais.github.io/)

| Área | Tecnologias e ferramentas |
| --- | --- |
| Front-end | HTML5, CSS3, JavaScript, Bootstrap e Angular |
| Back-end | C#, .NET, ASP.NET MVC, Web Forms e desenvolvimento de APIs com ASP.NET Core |
| Bancos de dados | SQL Server e MySQL |
| Tools | Visual Studio, Git, GitHub e Postman |

## Estrutura

- `index.html` contém a página do portfólio.
- `css/styles.css` define o layout e a adaptação para telas menores.
- `img/juliano.jpeg` contém a foto de perfil.
- `img/logo-soma.png` contém a logo da Soma Soluções Digitais.

## Visualização local

Abra `index.html` no navegador. A página usa HTML e CSS estáticos. A fonte Roboto e os ícones Devicon são carregados pela internet.

## Publicação no GitHub Pages

A publicação usa a branch `master` e a pasta `/ (root)`. Para aplicar esta atualização ao repositório existente, copie `index.html`, `README.md`, `css/styles.css` e `img/logo-soma.png` para os caminhos correspondentes. Mantenha o arquivo `img/juliano.jpeg` que já está no repositório.

Envie as alterações para a branch `master` e acompanhe a publicação na aba **Actions**. Quando concluir, abra o link do portfólio e confira a página.
